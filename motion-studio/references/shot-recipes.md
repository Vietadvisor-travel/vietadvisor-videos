# Shot recipes — named sequences you can paste and adapt

Each recipe is a small directed sequence (2–3 beats). Change places, people and words; keep the grammar.
Never use the same recipe twice in one video.

**Arrival** (new place, awe)
```
# reveal place=ninhbinh hero=dave shot=EWS lens=wide light=day cam=crane fg=bamboo
# talk place=ninhbinh host=linh shots="MS linh|CU dave low" cam=breathe
```
**The cold open** (sensory first, words later)
```
# moment kind=steam dish=pho capAt=1.2
```
**Wrong way → right way** (comedy + advice)
```
# gag place=oldquarter hero=dave ...            ← hero does it wrong
# dialogue a=dave b=cophovn ... fg=wires       ← local corrects him (button line)
# moment kind=crossing hero=dave               ← he does it right
```
**Journey montage** (distance, time passing)
```
# moment kind=mapdive to=hagiang label="HÀ GIANG"
# moment kind=pass hero=dave time=sunset
# moment kind=window time=sunset hero=linh     ← quiet beat, music up, 1 line or none
```
**Storm beat** (pattern interrupt, mid-video)
```
# moment kind=downpour place=oldquarter trans=glitch
# talk place=sidewalk host=linh light=day cam=arc ← "15 minutes later…"
```
**Taste** (food climax)
```
# moment kind=steam dish=buncha
```

## Camera vocabulary (use `cam=` — combine with `+`, e.g. `cam=crane+breathe`)
| move | feeling |
|---|---|
| `crane` / `craneDown` | rise to reveal / settle into intimacy |
| `vertigo` | realisation, awe, "wait…" — subject grows, world falls away |
| `arc` | circling a character in a key moment |
| `snap` / `crashZoom` | comic hit, shock |
| `whip` | fast change of subject or place |
| `breathe` | living still frame for talk beats |
| `pushIn` / `pullOut` / `reveal` | focus / context / discovery |
| `dutch` / `handheld` | unease, energy |

## Acting vocabulary — `act="dave:shade|linh:walk:1>wave"` on any beat (per character; chains with `>`)
Loops: `talk chopsticks slurp sip paddle row selfie lookAround shade nod headshake laugh stretch wipe shiver
pray stir bargain count beckon fistpump jumpJoy crossArms leanBack sneak tired phone pole tour fanDance kneel
sitFloor` + classics `wave point pointUp cheer thumbs shrug hips think hold present eat photo facepalm scared
clap bow carry dance walk run sit toast`.
One-shots (play from their start): `release startle fall bowDeep pickUp throwUp`.
Chain: `pose="walk:1.2>stop:.3>shade:1.5>jumpJoy"` — seconds per segment, last one holds.
Hosts who talk with `pose=stand` gesture automatically.
