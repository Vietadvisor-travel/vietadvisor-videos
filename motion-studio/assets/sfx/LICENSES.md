# Sound-effect sample licences

Every file in `assets/sfx/` is a trimmed, mono 44.1 kHz Ogg Vorbis (q4) conversion of a sample released under
**CC0 1.0 Universal (public domain dedication)** - https://creativecommons.org/publicdomain/zero/1.0/ .
CC0 allows copying, modification, redistribution inside this package and commercial use, with no attribution required.
Credit is given below anyway (courtesy). Processing applied: leading-silence trim, max-length cut, 3 ms fade-in /
25 ms fade-out, DC removal, peak normalisation to -1 dBFS. Renamed to `<category>/<name>_<n>.ogg`.

Total: 253 files from 33 packs.
